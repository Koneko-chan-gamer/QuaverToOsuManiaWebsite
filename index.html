Conversion happens entirely in your browser — nothing is uploaded anywhere.
Key range: 1K through 10K (including full 10-key support). Maps above 10K are rejected.
BPM: read from Quaver timing points first, then the top-level BPM field, then auto-detected from note spacing using dominant-interval analysis + grid alignment scoring.
SV: negative multipliers (reverse scroll) and extreme values (teleport/freeze) are preserved. osu!mania supports negative SVs, but extreme values may be clamped.
KPS: average and peak keys-per-second (notes-per-second) are shown on each card.
Speed: anything other than 1× re-encodes the audio (MP3 when available, otherwise WAV), scales BPM and every timestamp. Title gets (1.5x Speed), difficulty gets (Sped Up / 1.5x) or (Slowed Down / 0.75x).
Pitch: with the switch on, pitch scales with the rate (nightcore/slowed style). With it off, tempo changes but pitch stays constant (WSOLA time-stretch).
Preview: uses the first loaded map's audio. If there's no audio, the button is disabled.
Lane indexing: both 0-indexed and 1-indexed .qua files are auto-detected and shifted so the playfield lines up in osu!mania.
